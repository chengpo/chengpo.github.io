I learned a useful git command today.

\n

Let's say I am working on a large code refactoring which would introduce a long change list.
\nFor the sake of maintenance, I make a working branch from my 'master' branch:

\n
$ git checkout -b code-refactoring\n
\n

Then I keep making small commit on my working branch. Obviously, I will end up with a bunch of\nsmall commits on the working branch.
\nAfter finish all the changes, I want to merge my commits back to the 'master' branch.

\n

But wait a second. To keep the commit log clean, I'd all the relevant changes be combined into one commit,\nthen merge it into my 'master' branch.

\n

To do so, all I need is just spell the magic commands:

\n
$ git checkout master\n$ git merge --squash code-refactoring\n$ git commit\n
\n

Voila, all the commits from code-refactoring branch be squashed into one large commit.
\nThat's it.

\n\n"}
