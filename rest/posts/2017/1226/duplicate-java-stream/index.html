From time to time, I was wondering how to clone a stream object.
\nBut it appears stream object is designed as 1 time use item, it does not support copying.\nSo, I ends up with duplicate the code for generating the stream.
\nSomething like:

\n
final long totalPapers = postIdRepository.getPostIdsByTag(tag).count();\nfinal List<Paper> papers = postIdRepository.getPostIdsByTag(tag)\n                                            /* some intermediate operations */\n                                            .collect(Collectors.toList());\n
\n

Well, it works. Just works in an ugly way though.

\n

Eventually, I realize instead of copy-paste code for generating the same stream object.\nI can decouple the logic for generating stream with the Supplier function interface.

\n

Here we go:

\n
final Supplier<Stream<Paper.Id>> postIds = () -> postIdRepository.getPostIdsByTag(tag);\n\nfinal long totalPapers = postIds.get().count();\n\nfinal List<Paper> papers = postIds.get()\n                                  /* some intermediate operations */\n                                  .collect(Collectors.toList());\n
\n

That's it. No more duplicate code.
